# 素材说明

`front`、`left`、`right`、`profile-left`、`profile-right` 是五个悬浮视角；同名 `-closed` 素材仅用于眼部小矩形采样，其身体区域不会参与渲染，不代表当前腿部姿态。

`walk-left.png` 和 `walk-right.png` 是脚掌放平的原始走路姿态。`walk-*-body.png` 为不含双腿的身体层，`walk-*-leg.png` 为独立单腿层，两条腿分别驱动。走路时复用相应侧面的眼部贴图。

`AppIcon.png` 是透明人物头像，`Icon/Ronova.icon` 是当前分层图标源文件，`Assets/Compiled` 是其已编译资源；`AppIcon.icns` 仅为旧版参考。`StatusHead-source.png` 是状态栏白色卡通头像的源图，`StatusHead.png` 是36像素 Retina 版本，显示尺寸18点。

素材通过内置图像生成工具制作和局部修改，生成来源标识见 `asset-manifest.json`（历史记录，不是外部下载链接）。应用头像和状态栏图标在记录之后追加，源图随项目提供。未包含用户参考视频、原始参考图、剪贴板截图或私有文件。

编辑约束：保持角色面部和服装；悬浮姿态脚尖向下，走路姿态脚掌放平；双腿靠近，避免大幅岔开；仅眼部参与眨眼切换。

角色及参考素材权利归其权利人。仓库暂未选择源码或美术素材许可证，不自动赋予第三方复制、修改、商用或再分发许可。

鞋型按用户参考图改为黑色尖头高跟鞋，在鞋面和脚踝保留细长嵌套菱形纹路及少量银色装饰；腿部必须是素色丝袜，不添加交叉纹路或花纹。

行走腿根由固定髋部权重与前景衣饰遮挡衔接；前景复用身体纹理与形变网格，不另存重复素材。身体与髋部共享轻微起伏，肩颈、头部及发丝随步伐延迟跟随。

髋部前景遮挡须覆盖臀侧及大腿旁下垂衣饰，不能只截取腰部，否则迈步时腿层会覆盖原本遮住臀部的衣摆。当前在纹理纵坐标 0.34–0.38 过渡至完整前景覆盖。

行走上半身通过 `WalkingUpperBody` 驱动：可见手臂围绕肩部反向摆动，手腕略有延迟；肩部转移重心，头部围绕颈部轻点并慢速微调朝向。眼部着色器在原有眨眼之外轻微收窄眼睑，身体与前景衣饰同步更新，避免前景盖住表情。使用 56×84 网格；验证脚本检查左右手腕、头部的可见位移和整周期网格无翻折。

行走时胸肩向前微移，左右分别校准，补偿侧面素材相对行走髋部偏后的姿势；位移从髋部向肩部渐增，避免整体前移导致腿根脱离。

摆臂相位直接取两脚的前后间距并反向驱动，手腕稍微滞后，保证双腿交叉时手臂连续通过中立位。回归检查覆盖左右方向每周期两次交叉时的手腕位移。

悬浮晃动按视角校准：正面保持原幅度；斜侧整体晃动为 65%、外侧发丝衣摆形变为 50%；纯侧面分别为 40% 和 25%。侧面身体及腿部区域不参与局部波浪形变，仅随整体平移和旋转，避免最大幅度下拉伸。`--qa --max --side --idle-samples --reference <输出目录>` 可导出最大幅度侧面关键帧及视频；QA 检查整周期身体网格边长变化。
